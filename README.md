# PGL-Navigation - Práctica de Navegación

## Descripción de la aplicación

Esta aplicación es un portfolio personal desarrollado para la práctica de navegación de la asignatura. La app muestra información personal, hobbies y un enlace QR al repositorio de GitHub.

## Funcionalidades implementadas

### Navegación principal
- **Drawer Navigation**: Menú lateral para navegar entre las diferentes secciones
- **Tab Navigation**: Pestañas inferiores en la sección de portfolio
- **Pantalla de bienvenida**: Página inicial con mensaje de bienvenida

### Secciones de la app

1. **Pantalla de Inicio**
   - Mensaje de bienvenida
   - Imagen
   - Botón para ir al portfolio

2. **Portfolio con Tabs**
   - **Inicio**: Descripción general
   - **Hobbies**: Lista de mis hobbies personales
   - **QR**: Código QR con enlace al repositorio GitHub

3. **Pantalla de Contador**
   - Contador con botones para incrementar, decrementar y resetear
   - Implementado con useState
